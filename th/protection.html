FIG. A — เงื่อนไขโครงการ

ประกันขาดทุนจากการก๊อปปี้เทรด

ถ้าคุณก๊อปปี้กลยุทธ์ตามเงื่อนไขด้านล่างครบหนึ่งเดือน แล้วเมื่อจบระยะคุ้มครองบัญชียังติดลบ เราคืนส่วนที่ขาดทุนนั้นเป็นเงินสด

โครงการนี้ตั้งอยู่บนหลักร่วมรับความเสี่ยงขาลง ไม่ใช่คำสัญญาว่าคุณจะไม่ขาดทุน ที่เขียนเงื่อนไขละเอียดเพราะคำสัญญาจะจ่ายไหวก็ต่อเมื่อเลเวอเรจและการแทรกแซงด้วยมือถูกจำกัด — ไม่อย่างนั้นคนที่ขยายสถานะจะเรียกร้องเกินกว่าที่โครงการรับไหว และสุดท้ายทุกคนที่อยู่ในโครงการเสียหายหมด กรุณาอ่านให้จบก่อนเข้าร่วม

01สรุปในประโยคเดียว

เปิดบัญชีกับแพลตฟอร์มพันธมิตรผ่านลิงก์ของ Presight สมัคร PRESIGHT ALPHA-1 ด้วยอัตราก๊อปปี้ 1:1 แจ้ง MT5 account ID ให้ @PresightAdminBot ทาง Telegram ทันทีที่เริ่มก๊อปปี้ แล้วก๊อปปี้ต่อเนื่องครบหนึ่งเดือนโดยไม่แทรกแซงด้วยมือและไม่ถอนเงิน ถ้าจบรอบแล้วบัญชีติดลบ เราคืนส่วนที่ขาดทุนเป็นเงินสด

มีสองขอบเขตที่ต้องจำไว้ก่อน: ความคุ้มครองใช้กับขาดทุนที่เกิดหลังจากคุณแจ้งบัญชีเท่านั้น และใช้เฉพาะออเดอร์ที่กลยุทธ์ปิดเอง — ขาดทุนของสถานะที่คุณปิดเองไม่อยู่ในความคุ้มครอง

02เงื่อนไขการเข้าร่วม

ต้องเข้าเงื่อนไขด้านล่างทุกข้อ ขาดข้อใดข้อหนึ่งก็อยู่นอกความคุ้มครอง

  1. บัญชีใหม่กับแพลตฟอร์มพันธมิตร เปิดผ่านลิงก์ทางการของ Presight และยืนยันตัวตน (KYC) แล้ว บัญชีที่มีอยู่เดิมสมัครเข้าร่วมไม่ได้
  2. สมัคร PRESIGHT ALPHA-1 ในระบบก๊อปปี้เทรดของแพลตฟอร์ม โดยตั้งค่าตามด้านล่าง เส้นทาง: ล็อกอิน secure.decodefx.com → Copy Trading → เข้าสู่ระบบด้วยเลขบัญชีและรหัสผ่านของบัญชี MT5 ที่ใช้ก๊อปปี้ → New subscription → กรอก Provider เป็น PRESIGHT ALPHA-1
  3. ตั้งค่าก๊อปปี้: Autoscale, Value by asset, Ratio = 1 — คือมิเรอร์ 1:1 ห้ามขยายขนาดสถานะของบัญชีต้นทาง Ratio เกิน 1 เท่ากับเสียสิทธิ์ทันที
  4. เมื่อเริ่มก๊อปปี้แล้ว แจ้ง MT5 account ID (เลขล็อกอิน) ทางข้อความส่วนตัวถึง @PresightAdminBot ใน Telegram — บอทจะตอบใบรับทันที บัญชีที่ไม่เคยแจ้ง เราตรวจสอบไม่ได้ จึงไม่เข้าเกณฑ์ ส่วนบัญชีที่แจ้งแล้ว ความคุ้มครองเริ่มนับจากวินาทีที่แจ้ง — ขาดทุนที่เกิดก่อนหน้านั้นอยู่นอกขอบเขต
  5. ก๊อปปี้ต่อเนื่องครบหนึ่งเดือน โดยไม่หยุดชั่วคราวและไม่ยกเลิกการสมัคร
  6. ระหว่างรอบ: ไม่เปิดออเดอร์เอง ไม่แก้จุดตัดขาดทุนหรือเป้าหมายเอง ไม่เปลี่ยนการตั้งค่าก๊อปปี้ (การปิดสถานะเองไม่ทำให้การเข้าร่วมทั้งรอบเป็นโมฆะ แต่ขาดทุนของออเดอร์นั้นไม่ได้รับความคุ้มครอง — ดูข้อ 06)
  7. ระหว่างรอบ: ไม่ถอนเงิน

03การคุมความเสี่ยงอยู่ฝั่งเรา

ALPHA-1 เป็นกลยุทธ์เชิงปริมาณและอาจถือหลายสถานะพร้อมกัน — นั่นคือวิธีที่กลยุทธ์ถูกสร้างขึ้น ไม่ใช่สัญญาณว่าความเสี่ยงหละหลวม เราจึงไม่ขอให้คุณตั้งเพดานความเสี่ยงต่อออเดอร์หรือจำนวนสถานะเอง พารามิเตอร์พวกนั้นจริง ๆ แล้วไม่ได้อยู่ในมือคุณ และการเขียนลงในเงื่อนไขก็มีแต่จะสร้างข้ออ้างให้เถียงกันภายหลัง

ความเสี่ยงเราจัดการที่ระดับบัญชีก๊อปปี้:

  • คุมดรอว์ดาวน์: บัญชีกลยุทธ์มีเกณฑ์ดรอว์ดาวน์ เมื่อแตะเกณฑ์จะลดขนาดสถานะหรือหยุดเปิดออเดอร์ใหม่โดยอัตโนมัติ และบัญชีก๊อปปี้ทำตาม
  • ความเสี่ยงต่อออเดอร์คงที่: ความเสี่ยงของแต่ละออเดอร์ถูกกำหนดที่บัญชีต้นทาง แล้วสะท้อนมาที่บัญชีคุณในอัตรา 1:1 ไม่โตตามยอดเงินของคุณ
  • เฝ้าดูความเสี่ยงรวม: ความเสี่ยงรวมของสถานะที่เปิดอยู่ทั้งหมดกลยุทธ์เป็นคนจัดการ จึงไม่ทบกันเป็นเส้นตรงตามจำนวนสถานะ
  • ไม่ถัวเฉลี่ยขาลง: กลยุทธ์ไม่เติมสถานะที่กำลังขาดทุน และไม่เล่นมาร์ติงเกล

สิ่งเดียวที่คุณต้องทำคือตั้งอัตราก๊อปปี้เป็น 1:1 แล้วปล่อยไว้

04ระยะคุ้มครอง

เริ่มนับ
ตอนที่คุณแจ้ง MT5 account ID ถ้าคุณแจ้งก่อนออเดอร์ก๊อปปี้แรก ให้เริ่มนับที่ออเดอร์แรกนั้นแทน (ยึดอันที่เกิดทีหลัง)
ระยะเวลา
หนึ่งเดือน — 30 วันปฏิทินติดต่อกัน
ก่อนแจ้งบัญชี
ขาดทุนที่เกิดก่อนคุณแจ้งบัญชีไม่ได้รับความคุ้มครอง และไม่นำมาเทียบกับเงินทุนตั้งต้น
ขยายเวลา
ถ้าถึงวันที่ 30 ยังมีสถานะเปิดค้างอยู่ ระยะเวลาจะขยายจนกว่าจะปิดหมด ขยายได้ไม่เกิน 3 วันทำการ
สิ้นสุด
การหยุดชั่วคราวหรือยกเลิกการสมัครระหว่างรอบทำให้ความคุ้มครองเป็นโมฆะ ไม่มีการจ่ายใด ๆ

05เงินทุนตั้งต้น

เงินทุนตั้งต้น
อิควิตี้ของบัญชี ณ วินาทีที่ระยะคุ้มครองเริ่มต้น — คือตอนที่คุณแจ้ง MT5 account ID (หรือที่ออเดอร์ก๊อปปี้แรก ถ้าคุณแจ้งไว้ก่อนหน้านั้น)
วงเงินคุ้มครอง
เท่าเงินทุนตั้งต้นทั้งจำนวน
การถอนเงิน
การถอนเงินระหว่างรอบจะคำนวณเงินทุนตั้งต้นใหม่เป็นอิควิตี้ต่ำสุดหลังถอน และทำให้การเข้าร่วมรอบนั้นเป็นโมฆะ

06วิธีคำนวณเงินชดเชย

ขาดทุนสุทธิ = เงินทุนตั้งต้น − อิควิตี้ตอนจบระยะคุ้มครอง

ความคุ้มครองใช้กับออเดอร์ที่กลยุทธ์ปิดเองเท่านั้น สถานะที่คุณปิดเองถูกตัดออกทั้งกำไรและขาดทุน — คุณเป็นคนเลือกจังหวะออก ผลลัพธ์นั้นจึงเป็นของคุณ ดังนั้น:

เงินชดเชย = ผลขาดทุนรวมของออเดอร์ที่กลยุทธ์ปิดในระยะคุ้มครอง โดยไม่เกินขาดทุนสุทธิข้างต้น

  • ขาดทุนสุทธิ ≤ 0 (บัญชีเสมอตัวหรือมีกำไร): ไม่มีการจ่าย
  • ออเดอร์ที่กลยุทธ์ปิดรวมกันแล้วเป็นกำไร: ไม่มีการจ่าย
  • ขาดทุนทั้งสองทาง: จ่ายตามจำนวนที่น้อยกว่า

ตัวอย่างที่ 1: เงินทุนตั้งต้น 10,000 ดอลลาร์ อิควิตี้ตอนจบ 9,150 ดอลลาร์ ทุกสถานะกลยุทธ์เป็นคนปิด ขาดทุนสุทธิ 850 ดอลลาร์ จ่าย 850 ดอลลาร์

ตัวอย่างที่ 2: ขาดทุน 850 ดอลลาร์เท่ากัน แต่ 300 ดอลลาร์มาจากสถานะที่คุณปิดเอง ส่วนที่กลยุทธ์ปิด ขาดทุน 550 ดอลลาร์ จ่าย 550 ดอลลาร์

รูปแบบการจ่าย
เงินสดสกุลดอลลาร์ โอนเข้าช่องทางรับเงินที่คุณระบุ
ระยะเวลา
ภายใน 10 วันทำการ หลังตรวจสอบเสร็จ
ค่าธรรมเนียม
Presight รับผิดชอบ ยกเว้นค่าธรรมเนียมของบุคคลภายนอกที่เกิดจากช่องทางรับเงินที่คุณเลือก

07ข้อยกเว้น

หากเข้าข้อใดข้อหนึ่งด้านล่าง การเข้าร่วมรอบนั้นจะเสียสิทธิ์:

  1. ไม่ได้แจ้ง MT5 account ID ให้ @PresightAdminBot หรือแจ้ง ID ที่ไม่ตรงกับบัญชีที่ยื่นเรื่อง
  2. ก๊อปปี้ไม่ครบหนึ่งเดือน หรือหยุดชั่วคราว/ยกเลิกการสมัครระหว่างรอบ
  3. เปิดออเดอร์เอง หรือแก้ไขสถานะที่เกิดจากการก๊อปปี้ด้วยมือ (จุดตัดขาดทุน เป้าหมาย การตั้งค่าก๊อปปี้)
  4. Ratio เกิน 1 — คือขยายขนาดสถานะของบัญชีต้นทาง
  5. ถอนเงินระหว่างระยะคุ้มครอง
  6. ใช้หลายบัญชีเข้าร่วมภายใต้ตัวตนเดียวกันหรือช่องทางรับเงินเดียวกัน
  7. พฤติกรรมที่แพลตฟอร์มพันธมิตรห้าม (latency arbitrage, hedged scalping, การอาศัยสลิปเพจ และอื่น ๆ ทำนองนี้)
  8. ให้ข้อมูลเท็จ หรือไม่ให้ความร่วมมือในการตรวจสอบ
  9. ขาดทุนที่ไม่ได้เกิดจาก PRESIGHT ALPHA-1 — เช่นคุณไปเทรดสินทรัพย์ที่กลยุทธ์ไม่ได้ยุ่งด้วย
  10. ขาดทุนที่เกิดจากระบบแพลตฟอร์มพันธมิตรขัดข้อง ราคาผิดพลาด หรือเหตุสุดวิสัย กรณีเหล่านี้พิจารณาเป็นราย ๆ ไป และอยู่นอกกลไกจ่ายอัตโนมัติ

การปิดสถานะเองเป็นข้อยกเว้นเดียว: ไม่ทำให้การเข้าร่วมเป็นโมฆะ แต่ขาดทุนของสถานะใดก็ตามที่คุณปิดเองจะไม่ได้รับความคุ้มครองเลย ส่วนที่เหลือของบัญชียังพิจารณาตามข้อ 06

08การตรวจสอบ

  1. ยื่นเรื่องผ่านคอมมูนิตี้หรืออีเมลภายใน 5 วันปฏิทิน นับจากวันที่รอบสิ้นสุด
  2. ส่งรายงานบัญชีฉบับสมบูรณ์จากแพลตฟอร์ม (ออเดอร์ทั้งหมดพร้อมรายการฝากถอนทั้งหมด) หรืออนุญาตให้แพลตฟอร์มแบ่งปันข้อมูลแบบอ่านอย่างเดียวกับ Presight
  3. เราตรวจสอบเวลาที่แจ้งบัญชี ประวัติการตั้งค่าก๊อปปี้ ออเดอร์ที่เกิดขึ้น และรายการฝากถอน พร้อมแยกทีละออเดอร์ว่าสถานะไหนกลยุทธ์เป็นคนปิด และสถานะไหนคุณปิดเอง
  4. ถ้าตรวจสอบผ่าน เราจ่ายตามข้อ 06 ถ้าไม่ผ่าน เราจะชี้แจงเหตุผลเป็นลายลักษณ์อักษร

09ข้อกำหนดอื่น ๆ

  1. โครงการนี้ไม่ใช่คำแนะนำการลงทุน และไม่รับประกันว่ากลยุทธ์จะทำกำไร เป็นเพียงข้อตกลงชดเชยความเสียหายภายใต้เงื่อนไขเฉพาะเท่านั้น
  2. Presight อาจแก้ไขหรือยุติโครงการเมื่อใดก็ได้ การทำเช่นนั้นไม่กระทบผู้เข้าร่วมที่อยู่ในระยะคุ้มครองแล้ว สิทธิ์ของพวกเขาเป็นไปตามเงื่อนไขที่มีผลในตอนที่เข้าร่วม
  3. โครงการนี้เป็นอิสระจากแคมเปญใด ๆ ที่แพลตฟอร์มพันธมิตรจัดขึ้น และแพลตฟอร์มนั้นไม่รับผิดชอบต่อโครงการนี้
  4. เงื่อนไขฉบับภาษาจีนเป็นฉบับที่มีผลบังคับ ฉบับภาษาไทยนี้ให้ไว้เพื่ออ้างอิงเท่านั้น

⚠ คำเตือนความเสี่ยงและการเปิดเผยผลประโยชน์ทับซ้อน

CFD ฟอเร็กซ์ และผลิตภัณฑ์เลเวอเรจมีความเสี่ยงสูง อาจทำให้คุณเสียเงินฝากทั้งหมด และไม่เหมาะกับนักลงทุนทุกคน ความคุ้มครองของโครงการนี้จำกัดที่เงินทุนตั้งต้น และไม่ได้ลบความเสี่ยงในการเทรด

Presight มีความสัมพันธ์แบบผู้แนะนำ (IB / affiliate) กับแพลตฟอร์มเทรดพันธมิตร ถ้าคุณเปิดบัญชีผ่านลิงก์ของเรา เราอาจได้รับค่าคอมมิชชันจากแพลตฟอร์ม สิ่งนี้ไม่ได้เพิ่มต้นทุนการเทรดของคุณ แต่คุณควรทราบว่าความสัมพันธ์นี้มีอยู่

ผลงานในอดีตไม่ได้บอกผลในอนาคต คุณมีหน้าที่ตรวจสอบเองว่าการเทรดลักษณะนี้ได้รับอนุญาตในเขตอำนาจศาลของคุณหรือไม่ และรับผิดชอบการตัดสินใจเทรดของตัวเอง
